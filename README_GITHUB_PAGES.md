# GitHub Pages Upload Guide / GitHub Pages 上传说明

## What This Package Is / 这个包是什么

This folder is the static independent store front for the Thailand launch.

这个文件夹是泰国独立站的静态前台页面。

- Home page: `index.html`
- Product page: `products/handheld-fan.html`
- Product page: `products/neck-fan.html`
- Images and assets: `assets/`
- Styles and scripts: `styles.css`, `script.js`

## GitHub Pages Steps / GitHub Pages 上传步骤

1. Create a GitHub repository, for example `yiming-thailand-store`.
2. Upload every file and folder inside this directory to the repository root.
3. Go to repository `Settings` -> `Pages`.
4. Choose `Deploy from a branch`.
5. Select branch `main` and folder `/root`.
6. Wait for GitHub to generate the public preview URL.

1. 新建 GitHub 仓库，例如 `yiming-thailand-store`。
2. 把本文件夹里的所有文件和文件夹上传到仓库根目录。
3. 进入仓库 `Settings` -> `Pages`。
4. 选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/root`。
6. 等 GitHub 生成公开预览链接。

## Important Before Real Ads / 正式投流前必须确认

- Disable the Shopify storefront password page before sending public traffic.
- Test both product links from the independent site to Shopify.
- Confirm THB prices, shipping, PayPal, and checkout flow.
- Use a custom domain for paid ads instead of the default `github.io` URL.

- 正式引流前，必须关闭 Shopify 前台密码页。
- 从独立站点击两个产品链接，确认能进入 Shopify 商品页。
- 确认泰铢价格、运费、PayPal 和结账流程。
- 付费广告建议使用自有域名，不建议直接投 `github.io` 链接。
