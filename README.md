# Yiming Thailand Store V2

这是泰国独立站的新版本草稿，基于旧项目 `独立站+泰国`、Shopify 店铺资料和新 Excel 产品池重新整理。

## 当前定位

- 市场：泰国
- 前台语言：英文为主，关键泰文辅助
- 主成交：Shopify 商品页
- 主推商品：
  - Handheld Fan / พัดลมมือถือ
  - Neck Fan / พัดลมคล้องคอ
- 后续商品池：
  - Shopify Draft 产品
  - Excel 新产品候选池

## 重要原则

- 1688 供应链接不显示在前台。
- 前台只突出能成交的商品和可信任信息。
- Draft / Excel 商品只作为后续扩品方向，避免客户误认为全部现货可下单。

## 本地预览
